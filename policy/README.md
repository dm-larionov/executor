# Политики dup-main

Заменять папку policy целиком безопасно только после сверки с репозиторием. В этом пакете учтены условия репозитория на 2026-10-20 12:10 (UTC), seq репозитория 2, внешних правил сохранено 1.

Папка создана расширением «МЭШ · Домашние задания» (окно «Условия работ») в формате node tools/policy.mjs publish-dir. Содержит только подписанные файлы: manifest.json, head.json, global.json, shards/, groups/, keys.json.
Закрытого ключа и списков ФИО здесь нет и быть не должно. Подробно: docs/POLICY.md и docs/TEACHER.md в проекте ДУП.03.
